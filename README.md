# Parkinson’s Disease Severity Prediction

This project compares Linear Regression, Regression Tree, and Multilayer Perceptron models for predicting Parkinson’s disease severity using telemonitoring data.

## Project Objectives

- Prepare and explore Parkinson’s telemonitoring data
- Analyze 16 predictor variables
- Train and compare multiple regression models
- Evaluate prediction error and residual patterns
- Compare model performance and training time

## Models

- Linear Regression
- Regression Tree
- Multilayer Perceptron Regressor

## Evaluation

- Mean Absolute Error
- Residual Analysis
- Model Comparison
- Training Time

## Tools

- Python
- pandas
- NumPy
- scikit-learn
- Matplotlib
- Jupyter Notebook

## Files

- `Parkinsons_Disease_Severity_Prediction.ipynb` — Complete analysis and model development
- `Parkinsons_Disease_Severity_Prediction_Report.pdf` — Project report

## Important Note

This project is for educational purposes and is not intended for medical diagnosis.
